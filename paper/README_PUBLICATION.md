## 💡 Tips for Success

### Writing Quality
1. **Be concise**: Every sentence should add value
2. **Show, don't tell**: Use concrete examples and data
3. **Be honest**: Clearly state limitations
4. **Be reproducible**: Provide all details needed to replicate

### Figure Quality
1. **Use vector graphics**: PDF format, not PNG/JPG
2. **Readable text**: Font size ≥10pt in figures
3. **Color-blind friendly**: Use distinct colors + patterns
4. **Consistent style**: Same font, colors across all figures

### Common Mistakes to Avoid
❌ Missing error bars or confidence intervals
❌ Claiming "novel" without comparing to baselines
❌ Vague future work ("improve performance")
❌ Overselling results or hiding limitations
❌ Poor figure quality (low resolution, unreadable)

## 🛠️ Troubleshooting

### LaTeX Compilation Issues

**Error: "File not found: figures/..."**
- Solution: Create `figures/` directory and generate figures

**Error: "Undefined control sequence"**
- Solution: Install missing packages (`texlive-full`)

**Error: "Citation undefined"**
- Solution: Run bibtex, then pdflatex again (2×)

**Warning: "Overfull hbox"**
- Solution: Adjust text or use `\sloppy` for that paragraph

### Figure Generation Issues

**Error: "No module named matplotlib"**
- Solution: `pip install matplotlib seaborn numpy networkx`

**Error: "Permission denied"**
- Solution: `chmod +x generate_figures.py`

**Figures look pixelated**
- Solution: Already set to 300 DPI, should be fine
- If needed, increase `dpi=600` in savefig() calls

### Common Questions

**Q: Can I use this draft as-is?**
A: Almost! Just add your name, create figures 1 & 4, and proofread.

**Q: How do I change the title?**
A: Edit line 27 in `publication_draft.tex`

**Q: Can I add more references?**
A: Yes! Add them to `references.bib` and cite with `\cite{key}`

**Q: How do I convert to single column?**
A: Change `\documentclass[11pt,twocolumn]{article}` to `\documentclass[11pt]{article}`
